# /specflow:status

Display SpecFlow project status:
- Current version and stage
- PCB file inventory (12 files: 00-08 + 09_codebase_analysis, 10_tech_stack, 11_architecture)
- Open questions count
- New input file detection

Usage: `/specflow:status` or `/specflow:status --json`
